Geocodificar direcciones de pasajeros

Sube un Excel con columnas identificador, nombre, direccion (y opcionalmente turno, barrio). El sistema corrige el formato de cada dirección y consulta su latitud/longitud reales contra el servicio de geocodificación — nunca se inventan coordenadas: lo que no se puede ubicar queda marcado como excepción para revisión manual.

Recomendado: incluye la columna barrio cuando la conozcas. En el Atlántico es común que el mismo nombre de calle (ej. "Calle 26") se repita en varios barrios de un mismo municipio — sin el barrio, el sistema puede confundir la calle correcta y dar una coordenada de un sector distinto.
